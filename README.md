# 🧬 RACIPE Project: EMT Modeling and Analysis

## 📊 Overview
Complete EMT analysis using RACIPE (Random Circuit Perturbation).

## 📁 Repository Contents
- **Notebooks**: Jupyter notebooks with complete analysis
- **Data**: CSV data files (RACIPE results + GSE69667)
- **Figures**: All generated plots and figures
- **Scripts**: Python scripts for modular code
- **JSON**: Summary files

## 📊 Key Results
- **RACIPE models:** 10,000
- **State distribution:** Epithelial 21.3%, Hybrid 38.5%, Mesenchymal 40.2%
- **EMT Score range:** 0.013 - 1.000
- **Real data:** GSE69667 (A549 + TGF-β)

## 🔍 Top Influential Genes
1. **E-cadherin** (r = -0.767)
2. **N-cadherin** (r = +0.584)

## 🚀 How to Run
1. Open the notebook in Google Colab
2. Upload the CSV files
3. Runtime -> Run all
